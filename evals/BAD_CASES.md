# Bad Case 与优化记录

## 已修复：否定/转折误分类

输入：`不是物流问题，而是订单 ORD-20260831011 的退款一直没到账。`

- Baseline：遇到文本左侧第一个关键词“物流”立即返回，误判为物流配送。
- 根因：关键词匹配没有理解“不是……而是……”的语义方向。
- 优化：否定分句权重降至 `0.12`，转折后的正向分句权重提升至 `1.75`；RAG 再按预测分类加权。
- 结果：识别为退款退货，并将 `KB-REF-001` 排到首位。

## 仍需生产验证的风险

1. 新品牌型号、方言、错别字和语音转写错误可能降低抽取与分类质量。
2. 多个问题同等重要时，单标签分类会丢失次要意图。
3. 词面相似但政策不同的知识文档需要更强的权限与时效重排。
4. 真正的工具超时、限流和部分成功需要真实系统的错误码映射。
5. ROI 必须用试点数据重新计算，不能沿用作品集默认假设。
