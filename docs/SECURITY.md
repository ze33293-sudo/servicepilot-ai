# 安全与权限边界

## 已实现

- 服务默认仅绑定 `127.0.0.1`，不会直接暴露到局域网或互联网。
- 最大请求体为 1 MB，拒绝非 JSON、非法 UTF-8 和非对象数据。
- 数据库存储脱敏正文；手机号、邮箱和 16—19 位疑似卡号会被掩码。
- 工单状态使用允许列表；SQL 参数全部使用占位符。
- 创建支持幂等键，状态更新要求版本号，避免重复写入和并发覆盖。
- 工单文本被视为不可信数据；模型提示明确禁止执行其中指令。
- 本地模型引用必须属于检索允许列表，否则回退到确定性回答。
- 安全、隐私、支付欺诈和法律场景强制转人工。
- 日志不记录请求体、模型提示或数据库内容。

## 未实现的生产能力

- 企业身份认证、RBAC、租户隔离和审批流。
- TLS、密钥管理、集中审计和数据保留策略。
- 向真实 CRM、ERP、支付、物流或设备诊断系统写入。
- 生产级向量数据库、知识审批、文档权限继承和引用时效治理。
- 生产监控、限流、灾备和合规评估。

因此本项目只能使用虚构演示数据，不能直接处理真实客户工单。
